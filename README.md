# Laser Runner — GitHub Pages 버전

업로드해 주신 PNG 에셋을 사용한 세로형 모바일 웹게임입니다.

## 포함된 기능

- 배경 PNG 사용
- 무빙워크 3프레임 무한 반복
- 캐릭터 달리기 4프레임
- 캐릭터 점프 4프레임
- 캐릭터 슬라이딩 4프레임
- 좌우 레이저 발사기 PNG 사용
- 레이저 빔은 코드로 렌더링
- 발사기와 레이저가 같은 원근 좌표로 함께 이동
- 낮은 레이저: 점프
- 높은 레이저: 슬라이딩
- 캐릭터 현재 이미지 크기를 기준으로 한 히트박스 충돌
- 시간이 지날수록 레이저 속도 증가
- 시간이 지날수록 생성 간격 감소
- 위/아래 스와이프 및 화면 버튼
- 최고 점수 브라우저 저장

## GitHub Pages 배포

1. 이 ZIP의 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다.
3. 압축을 푼 폴더의 내용 전체를 저장소 최상위 경로에 업로드합니다.
4. GitHub 저장소에서 `Settings > Pages`로 이동합니다.
5. 다음과 같이 설정합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save를 누릅니다.
7. 잠시 기다리면 다음 형태의 링크가 생성됩니다.

   `https://사용자이름.github.io/저장소이름/`

모바일에서 이 링크를 열면 게임이 실행됩니다.

## 로컬 테스트

Python이 설치되어 있다면 프로젝트 폴더에서:

```bash
python -m http.server 8000
```

브라우저에서:

```text
http://localhost:8000
```

## 조작

- 위 스와이프 / JUMP 버튼: 점프
- 아래 스와이프 / SLIDE 버튼: 슬라이딩
- PC 테스트:
  - Space / 위 방향키: 점프
  - 아래 방향키 / S: 슬라이딩

## 주요 조정값

`game.js` 상단의 `CONFIG`에서 수정할 수 있습니다.

- 캐릭터 크기
- 캐릭터 바닥 위치
- 점프 높이와 시간
- 슬라이딩 시간
- 무빙워크 애니메이션 FPS
- 레이저 초기 속도와 가속도
- 레이저 생성 간격
