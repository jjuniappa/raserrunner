# Laser Runner — GitHub Pages 버전

업로드해 주신 PNG 에셋을 사용한 세로형 모바일 웹게임입니다.

## 포함된 기능

- 배경 PNG 사용
- 무빙워크 3프레임 무한 반복
- 캐릭터 달리기 4프레임
- 캐릭터 점프 4프레임
- 캐릭터 슬라이딩 4프레임
- 좌우 레이저 발사기 PNG 사용
- 레이저 빔은 코드로 렌더링
- 발사기와 레이저가 같은 원근 좌표로 함께 이동
- 낮은 레이저: 점프
- 높은 레이저: 슬라이딩
- 캐릭터 현재 이미지 크기를 기준으로 한 히트박스 충돌
- 시간이 지날수록 레이저 속도 증가
- 시간이 지날수록 생성 간격 감소
- 위/아래 스와이프 및 화면 버튼
- 최고 점수 브라우저 저장

## GitHub Pages 배포

1. 이 ZIP의 압축을 풉니다.
2. GitHub에서 새 저장소를 만듭니다.
3. 압축을 푼 폴더의 내용 전체를 저장소 최상위 경로에 업로드합니다.
4. GitHub 저장소에서 `Settings > Pages`로 이동합니다.
5. 다음과 같이 설정합니다.
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. Save를 누릅니다.
7. 잠시 기다리면 다음 형태의 링크가 생성됩니다.

   `https://사용자이름.github.io/저장소이름/`

모바일에서 이 링크를 열면 게임이 실행됩니다.

## 로컬 테스트

Python이 설치되어 있다면 프로젝트 폴더에서:

```bash
python -m http.server 8000
```

브라우저에서:

```text
http://localhost:8000
```

## 조작

- 위 스와이프 / JUMP 버튼: 점프
- 아래 스와이프 / SLIDE 버튼: 슬라이딩
- PC 테스트:
  - Space / 위 방향키: 점프
  - 아래 방향키 / S: 슬라이딩

## 주요 조정값

`game.js` 상단의 `CONFIG`에서 수정할 수 있습니다.

- 캐릭터 크기
- 캐릭터 바닥 위치
- 점프 높이와 시간
- 슬라이딩 시간
- 무빙워크 애니메이션 FPS
- 레이저 초기 속도와 가속도
- 레이저 생성 간격


## v2 변경 사항

- 낮은 레이저와 높은 레이저의 화면 높이 차이를 크게 확대했습니다.
- 높은 레이저를 조금 더 굵게 표시해 빠르게 구분할 수 있습니다.
- 레이저 초기 이동 속도와 가속도를 높였습니다.
- 첫 레이저 생성 간격과 이후 생성 간격을 단축했습니다.
- 화면을 짧게 터치하면 점프합니다.
- 아래로 스와이프하면 슬라이딩합니다.
- 위로 스와이프해도 점프할 수 있습니다.


## v3 변경 사항

- 높은 레이저를 서 있는 캐릭터의 허리~가슴 높이로 낮췄습니다.
- 서 있으면 높은 레이저와 충돌하고, 슬라이딩하면 히트박스 위로 지나갑니다.
- 화면의 JUMP / SLIDE 버튼을 제거했습니다.
- 화면 터치로 점프하고 아래 스와이프로 슬라이딩합니다.
- 무빙워크 위에 레이저의 붉은 투영 그림자를 추가했습니다.
- 그림자는 거리와 접근 위치를 보여주는 시각 효과이며 충돌 판정에는 영향을 주지 않습니다.


## v4 변경 사항

- 높은 레이저와 발사기를 캐릭터보다 앞쪽 레이어에 렌더링합니다.
- 높은 레이저가 서 있는 캐릭터의 몸을 실제로 가로질러 보입니다.
- 낮은 레이저는 캐릭터 뒤쪽 레이어를 유지합니다.


## v5 변경 사항

- START 또는 RESTART를 누르면 화면 중앙에 3 → 2 → 1 카운트다운이 표시됩니다.
- 카운트다운 중에는 점프와 슬라이딩 입력이 비활성화됩니다.
- 레이저 이동, 장애물 생성, 점수와 플레이 시간은 카운트다운 종료 후 시작됩니다.


## v6 변경 사항

- 게임 시작 시 3 → 2 → 1 카운트다운은 그대로 유지됩니다.
- 첫 번째부터 세 번째 레이저까지 접근 시 회피 타이밍 숫자가 표시됩니다.
- 충돌 약 0.9초 전 `3`, 약 0.6초 전 `2`, 약 0.3초 전 `1`이 표시됩니다.
- `1`이 사라지는 시점에 점프 또는 슬라이딩하면 됩니다.
- 세 번째 레이저가 지나간 뒤에는 회피 타이밍 안내가 다시 표시되지 않습니다.
- 색상은 3=흰색, 2=노란색, 1=빨간색입니다.


## v7
- 발사기는 항상 캐릭터 뒤.
- 낮은 레이저 빔은 캐릭터 뒤.
- 높은 레이저 빔은 캐릭터 앞.


## v9 변경 사항

- v7을 기준으로 다시 제작했습니다.
- 플레이 중 처음 세 개 레이저에 나오던 회피 타이밍 숫자만 제거했습니다.
- START 또는 RESTART 후 시작 전 `3 → 2 → 1` 카운트다운은 유지됩니다.
- 카운트다운 종료 후 게임이 정상적으로 시작됩니다.
- v7의 레이저 가림 순서, 그림자, 터치 점프, 아래 스와이프 슬라이딩을 유지합니다.
